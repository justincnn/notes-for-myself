## 前言

随着大家对垃圾推送越来越抗拒，特别是国内部分手机厂商和互联网大厂的频繁通知，推送似乎慢慢变成了一个贬义词。其实早在黑莓手机时代，推送是一种高端、高效的信息获取方式。

虽然厂商的推送体验很糟糕，但我们可以建立自己的消息推送渠道。除了 iOS 上的 Bark 之外，**Telegram Bot** 也是一个非常可靠、免费且跨平台的选择。本文就来手把手教你申请一个 Telegram 推送机器人。

![BotFather 聊天界面]([https:/cdn.jsdelivr.net/gh/justincnn/pictures/img/202307231625434.png](https:/cdn.jsdelivr.net/gh/justincnn/pictures/img/202307231625434.png))

> 由于 Telegram 服务在国内无法直接访问，请确保你的网络环境可以正常连接 Telegram。

## 1. 打开 BotFather

在 Telegram 中搜索 `@BotFather`，这是 Telegram 官方的机器人管理工具。找到后点击 **Start** 开始对话。

## 2. 创建新机器人

在聊天窗口中输入以下命令：

```text

/newbot

```

`BotFather` 会引导你完成后续步骤。

## 3. 设置机器人名称与 ID

按提示依次输入：

1. **机器人显示名称**：可以随意填写，比如 `My Push Bot`。

2. **机器人用户名（ID）**：必须以 `bot` 结尾，例如 `telegram_bot`。

创建成功后`BotFather` 会返回一段 API Token，类似：

```text

123456789:AAFakeTokenExample1234567890abcdef

```

## 4. 保管好你的 Token

Token 是操控机器人的唯一凭证，**请务必保密**，不要提交到 GitHub、博客或任何公开渠道。

> 建议将 Token 保存在密码管理器中。如果泄露，可以通过 `BotFather` 使用 `/revoke` 重新生成 Token，旧 Token 会立即失效。

## 5. 获取 Chat ID

有了 Token 之后，还需要知道要把消息推送给谁，也就是获取 Chat ID。

### 5.1 添加机器人为好友

先搜索你的机器人用户名，点击 **Start** 或发送一条任意消息。

### 5.2 打开 getUpdates 接口

在浏览器中访问以下地址，将 `<BOT_TOKEN>` 替换为你在上一步获取的 Token：

```text

[https://api.telegram.org/bot<BOT_TOKEN>/getUpdates](https://api.telegram.org/bot<BOT_TOKEN>/getUpdates)

```

例如：

```text

[https://api.telegram.org/bot123456789:AAFakeTokenExample1234567890abcdef/getUpdates](https://api.telegram.org/bot123456789:AAFakeTokenExample1234567890abcdef/getUpdates)

```

### 5.3 查找 Chat ID

在返回的 JSON 数据中，找到 `"chat":{"id":...}` 字段：

- 如果是与机器人的**私聊**，Chat ID 通常是一个**正整数**。

- 如果是**群组或频道**，Chat ID 通常是一个**负数**（例如 `-1001234567890`）。

请记录下这个 ID，它就是你的消息接收地址。

> 如果在 `getUpdates` 中没有看到数据，说明你还没有给机器人发送过消息。先在聊天窗口发一条 `/start`，再刷新上面的页面。

### 5.4 测试推送消息

使用 `curl` 命令测试发送：

```bash

curl -X POST "[https://api.telegram.org/bot<BOT_TOKEN>/sendMessage](https://api.telegram.org/bot<BOT_TOKEN>/sendMessage)" \

  -d "chat_id=<CHAT_ID>&text=my sample text"

```

将 `<BOT_TOKEN>` 和 `<CHAT_ID>` 替换为实际值。如果一切正常，你的 Telegram 会立刻收到一条 `my sample text` 消息。

## 总结

通过以上步骤，你已经成功创建了一个 Telegram 推送机器人。后续只需要调用 `sendMessage` 接口,就可以把服务器告警、网站通知、定时任务结果等任意消息推送到自己的 Telegram。

相比国内厂商的推送服务，Telegram Bot 的优点很明显：

- **免费**，没有数量限制

- **跨平台**，支持 iOS、Android、桌面端

- **接口简单**，一个 `curl` 命令即可完成推送

- **隐私性好**，消息只推给你自己
