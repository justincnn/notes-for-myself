Serv00 是一个为开发者提供免费虚拟主机的平台，自带面板管理、SSH 访问和多种实用功能。相比普通免费空间，Serv00 更灵活：可以运行 Node.js、Python 脚本、反向代理，还能部署图床、探针、代理节点等应用。

本文汇总了 Serv00 的**常用命令、PHP 保活方法**，以及社区中常用的部署案例（兰空图床、哪吒探针、New API、HY2 节点），方便你在一篇文章中找到所有关键步骤。

## 一、Serv00 常用命令

### 1.1 重置系统方案 A：手动清理

如果你只想清空「家目录」下的文件，而不动系统设置，可以按顺序执行以下命令。

**1. 纠正文件权限：**

```sh
find ~ -type f -exec chmod 644 {} \; 2>/dev/null
find ~ -type d -exec chmod 755 {} \; 2>/dev/null
```

**2. 删除文件：**

```sh
find ~ -type f -exec rm -f {} \; 2>/dev/null
```

**3. 删除空目录：**

```sh
find ~ -type d -empty -exec rmdir {} \; 2>/dev/null
```

**4. 再次尝试彻底清理剩余文件：**

```sh
find ~ -exec rm -rf {} \; 2>/dev/null
```

> 不建议对 `~` 全盘 `rm -rf`，可以先用前三条命令谨慎清理。

### 1.2 重置系统方案 B：社区一键脚本

如果你想要快速恢复系统环境，可以使用 k0baya 的一键重置脚本：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/k0baya/x-for-serv00/main/reset.sh)
```

### 1.3 重启 Serv00「进程环境」

Serv00 更适合使用 `pkill` 来结束用户所有进程，类似于重启：

```sh
pkill -kill -u <username>
```

将 `<username>` 替换为你的 Serv00 用户名，执行后当前用户的所有进程都会被终止。

## 2. Serv00 PHP 保活

Serv00 支持通过 PHP 脚本来创建 cron 定时任务，从而「保活」其他项目或脚本。

### 2.1 开启 PHP exec

1. 进入 Serv00 网站域名设置，打开对应域名的 **PHP exec** 功能。

   ![打开 PHP exec](https://cdn.jsdelivr.net/gh/justincnn/pictures@master/upic/V5GiWj%20.png)

2. SSH 登录 Serv00，执行：

```bash
bash <(curl -sL https://txt.0nz.de/serv00.sh)
```

### 2.2 添加定时任务

脚本运行后会生成一个带有参数的 PHP 访问地址。你可以：

- 在浏览器手动点击该网址，让服务被访问一次；
- 或者使用 `cron-job.org` 等定时任务平台，自动定期访问该网址，达到保活效果。

## 4. 在 Serv00 部署 New API

New API 是一个 OpenAI API 转发与管理面板，很多用户会把它部署在 Serv00 上。

### 4.1 下载 New API 二进制文件

```bash
cd /usr/home/用户名/domains/你的域名/public_html
release_info=$(curl -s https://api.github.com/repos/k0baya/new-api-freebsd/releases/latest)
asset_url=$(echo "$release_info" | jq -r '.assets[] | select(.name != "source code") | .browser_download_url')
curl -L -o newapi "$asset_url" && chmod +x newapi
```

### 4.2 创建启动脚本

在 `public_html` 目录下新建 `start.sh`：

```sh
export TIKTOKEN_CACHE_DIR="/home/你的用户名/domains/你的域名/public_html"
# 把下一行的 PORT 改为自己放行的端口
exec ./newapi --port PORT --log-dir ./logs
```

### 4.3 设置自动更新脚本

在 `domains` 目录下创建 `update.py`：

```python
#!/usr/local/bin/python

import os
import time
import requests
import subprocess
from datetime import datetime, timedelta
import logging

# 用户配置项
USERNAME = '你的用户名'
DOMAIN = '你的域名'
WORK_DIR = f'/home/{USERNAME}/domains/{DOMAIN}/public_html'
LOG_FILE = f'/home/{USERNAME}/domains/update.log'
GITHUB_PROJECT = 'eggacheb/new-api-freebsd'

logging.basicConfig(filename=LOG_FILE, level=logging.INFO, format='%(asctime)s %(levelname)s:%(message)s')

def update_service():
    try:
        # 获取最新版本信息
        url = f"https://api.github.com/repos/{GITHUB_PROJECT}/releases/latest"
        response = requests.get(url)
        response.raise_for_status()
        release = response.json()

        asset_url = next((asset['browser_download_url'] for asset in release.get('assets', []) if asset['name'] != 'source code'), None)
        if not asset_url:
            logging.error("No asset URL found")
            return

        # 下载新版本
        subprocess.run(["curl", "-L", "-o", f"{WORK_DIR}/newapi_new", asset_url], check=True)
        subprocess.run(["chmod", "+x", f"{WORK_DIR}/newapi_new"], check=True)

        # 停止服务，更新，然后重启
        subprocess.run(["killall", "-u", f"{USERNAME}"], check=True)
        subprocess.run(["mv", f"{WORK_DIR}/newapi_new", f"{WORK_DIR}/newapi"], check=True)
        subprocess.run([f"/home/{USERNAME}/.npm-global/bin/pm2", "resurrect"], check=True)

        # 更新版本信息
        with open(f"{WORK_DIR}/read.me", "w") as file:
            file.write(f"Version: {release['tag_name']}\n")

        logging.info(f"Updated to version {release['tag_name']}")
    except Exception as e:
        logging.error(f"Error during update process: {e}")

def main():
    while True:
        now = datetime.now()
        next_run = now.replace(hour=3, minute=0, second=0, microsecond=0)
        if now >= next_run:
            next_run += timedelta(days=1)
        
        time.sleep((next_run - now).total_seconds())
        update_service()

if __name__ == "__main__":
    main()
```

### 4.4 配置 PM2 启动两个进程

在 `domains` 目录下新建 `ecosystem.config.js`，并把 `$username`、`$domain` 替换为自己的信息：

```js
module.exports = {
  apps: [
    {
      name: 'newapi',
      script: './start.sh',
      cwd: '/home/$username/domains/$domain/public_html',
      interpreter: 'bash'
    },
    {
      name: 'update-newapi',
      script: './update.py',
      cwd: '/home/$username/domains',
      interpreter: '/usr/local/bin/python'
    }
  ]
};
```

### 4.5 启动并保存 PM2 快照

```bash
cd ~/domains && ~/.npm-global/bin/pm2 start ecosystem.config.js
```

启动后记得保存快照，防止重启后任务丢失：

```bash
~/.npm-global/bin/pm2 save
```

### 4.6 添加开机自启

据说 Serv00 会不定期重启，所以在 Panel 中也可以添加一个 Cron 任务，内容为：

```bash
/home/$username/.npm-global/bin/pm2 resurrect
```

## 5. 搭建兰空图床

### 5.1 添加域名

先在 Serv00 Panel 中添加你的域名，例如 `xx.xxx.com`，并在 Cloudflare 中添加 DNS 记录：

- 记录类型：`A`
- 名称：`img` 或 `yourdomain`
- 值：你的 Serv00 IP
- **代理状态**：不要打开（即关闭小黄云）

### 5.2 添加 SSL 证书

回到 Serv00 的 **WWW Website → Manage SSL certificates**，为你的域名添加证书。

### 5.3 下载兰空图床

SSH 登录 Serv00，进入你的网站目录：

```bash
cd domains/xx.xxx.com
```

依次执行：

```bash
release_info=$(curl -s https://api.github.com/repos/lsky-org/lsky-pro/releases/latest)
asset_url=$(echo "$release_info" | jq -r '.assets[] | select(.name != "source code") | .browser_download_url')
curl -L -o temp.zip "$asset_url" && unzip -q temp.zip && rm -f temp.zip
rm -rf public_html && ln -s "$PWD/public" "$PWD/public_html"
```

### 5.4 在 Panel 中设置基于目录开放路径

进入你的网站设置，在 **Open BaseDir directories** 中追加：

```yaml
:/usr/home/User/domains/xx.xxx.com
```

请把 `User` 和 `xx.xxx.com` 替换为自己的信息。

### 5.5 创建数据库

Serv00 后台 → Database，创建一个 SQL 数据库，记下数据库名、用户名和密码。

### 5.6 网页安装

访问你的域名，按提示设置：

- 数据库连接地址：填写 Serv00 给你发送的邮件中的数据库地址
- 数据库用户名、密码、库名：填写刚创建的数据库信息

安装成功后，可以使用你设置的管理员账号登录。

### 5.7 赋予上传权限

```bash
chmod -R 777 /usr/home/USER/domains/xx.xxx.com/storage
```

把 `USER` 和 `xx.xxx.com` 替换为自己的信息，否则图床无法上传图片。

### 5.8 保活计划

与前面介绍的方法一样，如果你需要保活图床，可以使用 PHP 保活脚本或 Cron 任务。

### 5.9 Upic 上传配置

UpiPic 因为版本原因需要自定义 API 才能上传到兰空图床。

**获取 token：**

```bash
curl -X POST -F "email=email@address" -F "password=your_passwd" https://your.domain/api/v1/tokens
```

**Upic 自定义 Host：**

- Host：`POST /api/v1/upload`
- 文件字段：`file`
- URL：`["data", "links", "url"]`

**其他字段：**

- `Content-Type: multipart/form-data`
- `Accept: application/json`
- `Authorization: Bearer 1|FWzOLxTGKhlT51m2oxxxxxxxxxxxxxxx`

> 注意：`Authorization` 的值是 `Bearer` 空格加 `token`。「Bearer」注意中间有一个空格。

## 6. 部署哪吒探针

哪吒探针是一款开源、轻量级的服务器监控工具，可以实时显示 CPU、内存、流量等信息，适合多台服务器集中监控。

### 6.1 准备工作

- 获取 Serv00 IP（在自带域名 DNS 中查看 A 记录即可）
- 在面板开放一个 TCP 端口
- 在 Cloudflare 添加子域名，A 记录解析到 Serv00 IP，代理状态建议关闭

### 6.2 安装哪吒探针

SSH 登录 Serv00 执行：

```bash
git clone https://github.com/vfhky/serv00_ct8_nezha.git
cd serv00_ct8_nezha
vim config/host.eg   # 添加需要保活的主机信息
```

## 7. Serv00 一键创建 HY2 节点

Hysteria2（HY2）是一款基于 UDP 的代理协议，适合在弱网环境使用。Serv Serv挂上社区的一键脚本：

### 7.1 面板允许运行应用

按照提示：

- 选择 `1`，安装并重新登录 SSH
- 选择 `7`，自动分配 UDP 端口、IP、UUID
