WebDAV（Web Distributed Authoring and Versioning）是一种基于 HTTP 协议的文件管理技术，让你可以在远程服务器上高效地管理和共享文件。它不仅支持文件的上传、下载，还支持文件夹的创建、删除和修改，能够把网络存储变成类似本地磁盘的体验。WebDAV 被广泛应用于企业协作、云存储（如 Koofr、Nextcloud）和个人文件同步等场景，兼容性强且配置简单。如果你想更高效地管理云端文件，WebDAV 值得一试！

## 国内

国内支持 WebDAV 的免费网盘中，最常用的当属**坚果云**。

### 坚果云

**免费额度**

免费版不限制存储空间，但每月有上传和下载流量限制，适合个人轻量同步使用。

**配置步骤**

1. 注册[坚果云账号](https://www.jianguoyun.com/d/signup)。
2. 登录后进入 **账户信息 → 安全选项**。
3. 在“应用密码”中设置专用密码。
4. 将下面的 WebDAV 信息填入你的客户端。

**WebDAV 信息**

```text
服务器地址：https://dav.jianguoyun.com/dav/
账户：注册邮箱
密码：应用密码
```

> **注意**：这里的密码是“应用密码”，不是坚果云的登录密码。

## 国外

### Koofr

**免费额度**

免费版提供 **10GB** 存储空间。

**特色**

- 支持将 OneDrive 和 Google Drive 挂载为 WebDAV，轻松解决第三方网盘不支持 WebDAV 的问题。
- 免费账号最多可挂载 **2 个第三方网盘**。

**配置步骤**

1. 前往 [koofr.net](https://k00.fr/3jurgejd) 注册账号。
2. 登录后进入主页，点击 **Connect**，选择一个云盘进行挂载（以 OneDrive 为例）。
3. 点击头像进入 **Preferences → Password**，点击 **Generate App Password** 生成应用密码。
4. 根据是否挂载第三方网盘，选择对应的 WebDAV 地址填入客户端。

**挂载 OneDrive 后的 WebDAV 信息**

```text
服务器地址：https://app.koofr.net/dav/OneDrive
账户：注册邮箱
密码：App Password
```

**未挂载第三方网盘的 WebDAV 信息**

```text
服务器地址：https://app.koofr.net/dav/
账户：注册邮箱
密码：App Password
```

### Infini-cloud

**免费额度**

免费版提供 **20GB** WebDAV 空间。使用推广码 `3VVG5` 注册，人均可额外获得 5GB 空间。

**配置步骤**

1. 前往 [infini-cloud.net](https://infini-cloud.net/en/) 注册，输入推广码 `3VVG5`。
2. 登录后进入 **My Page**。
3. 在页面中查看或生成 WebDAV 连接信息。

**WebDAV 信息**

```text
服务器地址：以 My Page 页面展示的地址为准
账户：注册邮箱
密码：My Page 中展示的密码
```

> **提示**：将 WebDAV 地址、账户和密码填入支持 WebDAV 的工具（如 RaiDrive、Cyberduck），即可像本地磁盘一样访问云端文件。
